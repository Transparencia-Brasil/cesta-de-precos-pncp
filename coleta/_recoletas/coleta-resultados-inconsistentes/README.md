# Recoleta de resultados inconsistentes

Recoleta realizada em 28/03/2025 após verificar que haviam resultados de itens que estavam inconsistentes.

O script `tasks/unifica-dados/src/12-bugfix-itens-resultados-inconsistentes.R` foi utilizado para:

- Separar os dados inconsistentes
- Enviar dados inconsistentes para serem recoletados em uma máquina virtual

A recoleta na máquina virtual foi feita usando os scripts que estão na pasta `coleta/_recoletas/coleta-resultados-inconsistentes/src`

Depois de recoletados, os dados foram abertos novamente em `12-bugfix-itens-resultados-inconsistentes.R` e unificados com os dados originais.
